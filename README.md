✨ Clínica de Estética - Sistema de Gestão

Este é um sistema completo de gestão para clínicas de estética, focado em proporcionar uma experiência elegante e eficiente tanto para 
profissionais quanto para clientes. O sistema oferece controle de agenda, gestão financeira, base de clientes e painel administrativo.

- 📅 **Agenda Inteligente**: visualize seus compromissos diários, gerencie novos agendamentos e acompanhe o status de cada atendimento.
- 💰 **Gestão Financeira**: controle total de entradas, saídas, comissões de colaboradores e fechamento de caixa mensal.
- 👥 **Base de Clientes**: cadastro completo com histórico de prontuários, pacotes adquiridos e lembranças de aniversários.
- 📊 **Painel Administrativo**: visão geral com estatísticas de faturamento, ticket médio e desempenho da equipe.
- 📲 **Integração WhatsApp**: confirmação de agendamentos e mensagens de aniversário com um clique.
